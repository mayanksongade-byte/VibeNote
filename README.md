# VibeNote

Every Thought Has a Vibe.

A modern Flutter note-taking application with beautiful UI, biometric security, reminders, voice notes, templates, and much more.

## Features

- Create & Edit Notes
- PIN & Biometric Lock
- Voice to Note
- Reminder Notifications
- Favourite Notes
- Pinned Notes
- Archive
- Image Notes
- Smart Categories
- Templates
- Dark Mode
- Modern Glassmorphism UI

## Tech Stack

- Flutter
- Dart
- Firebase
- Shared Preferences
- Local Notifications
